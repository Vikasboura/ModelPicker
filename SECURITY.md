# Security Policy

## Supported Versions

ModelPicker receives regular security updates on the main branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

Security and privacy are taken very seriously. If you discover a potential vulnerability in ModelPicker, please report it responsibly rather than opening a public issue.

### Contact Information

Please email your vulnerability report directly to:
**[contact@vikasboura.dev](mailto:contact@vikasboura.dev)**

### What to Include in Your Report
- A description of the issue and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Any suggested mitigations or patches, if available.

### What to Expect
- **Acknowledgement**: You will receive an initial response within 48 hours acknowledging receipt of your report.
- **Assessment**: The issue will be triaged and verified in an isolated environment.
- **Resolution**: A fix will be developed, tested, and released promptly.
- **Disclosure**: Coordinated public disclosure will happen after a fix is published.

Thank you for helping keep ModelPicker and its users safe.
